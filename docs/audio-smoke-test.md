# 효과음 수동 테스트 · 약 3분

로컬 실행: `npm run dev`. Electron 창에서 테스트합니다.

| 순서 | 조작 | 기대 결과 |
| --- | --- | --- |
| 1 | 오브제를 한 번 클릭하고 다시 클릭 | 세션 목록이 열리고 닫힘. 각 동작에 효과음 한 번 |
| 1-1 | 목록에서 제공자 펼치기·접기, 닫기 버튼·Escape로 닫기 | 모두 무음 |
| 2 | 오브제 아래 **미리보기**에서 작업 중 → 확인 필요 → 완료 → 오류 → 쉬는 중 선택 | 앞의 네 상태는 서로 다른 효과음과 모션. 쉬는 중은 무음 |
| 3 | 오브제 우클릭 → **설정…** → **소리**. 음량을 20%와 80%로 바꾸며 **미리 듣기** | 완료음 크기가 달라짐 |
| 4 | **효과음** 끄기. 오브제 창에서 2번 반복 | 모션은 바뀌고 소리는 안 남. 설정의 미리 듣기 버튼 비활성화 |
| 5 | 효과음을 다시 켜고, 오브제에서 Tab으로 버튼에 포커스 후 Enter로 열고 닫기 | 키보드 조작도 동작당 효과음 한 번. 드래그로 이동할 때는 패널 효과음 없음 |
| 6 | 음량 30%·효과음 끄기로 저장. 앱을 완전히 종료한 뒤 `npm run dev` 재실행 | 설정 유지, 시작 시 무음. 테스트 후 원하는 음량과 켜짐 상태로 복구 |

실제 이벤트 확인: 미리보기를 **실제 상태**로 되돌리고 오브제를 한 번 누른 뒤, 연결된 Claude/Codex에서 새 작업을 실행합니다. 작업 시작·확인 요청·완료·오류가 실제로 발생했을 때만 해당 알림이 한 번 들리는지 확인합니다. 미리보기는 소리·모션 확인용이며 실제 세션 수신 검증은 이 단계에서 합니다.

참고: 앱 재실행 후 오브제 창을 한 번 클릭하거나 키보드로 조작해야 해당 창의 오디오가 활성화됩니다. 작업 중 반복음은 없습니다.

## macOS UI 확인

- **활성 세션:** 오브제 클릭 → 제공자 펼치기 → 프로젝트·상태 확인. 내부 조작은 무음. Escape로 닫으면 오브제에 포커스가 돌아옵니다.
- **설정:** `⌘,` → 일반·소리·연결·정보 탭. 방향키로 탭 전환, 연결 진단 펼치기, 창을 닫았다 열어 마지막 탭 복원 확인. 긴 내용은 탭 아래에서 스크롤됩니다.
- **메뉴 막대:** 제공자 아이콘 클릭 → 남은 사용량·재설정 시각 확인. 연결되지 않은 제공자는 안내로 표시됩니다. 새로 고침 실패는 창 내부에 표시되며, 설정을 열면 사용량 창은 닫힙니다.
